# Custom Blockchain & Cryptocurrency Network Simulation

A localized blockchain network simulating cryptocurrency transaction nodes, wallet interactions, and smart contract structures using Python, Ganache, and MetaMask.

### 📈 Project Roadmap & Backlog
* **Origin:** Developed during middle school (6th/7th grade) as an early exploration into Web3 architectures.
* **Current Status:** Retained as a foundational portfolio piece demonstrating core conceptual logic.
* **Next Steps:** Currently planning a 3–4 month revision sprint to refactor the Python code, update legacy Web3 dependencies, and optimize transaction validations.
